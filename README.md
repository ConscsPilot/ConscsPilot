 Current project: Sirangua

Sirangua is a personal garden automation and plant intelligence app. It is designed to help track plant health, identify plants from photos, visualize sunlight/irradiance, and connect live sensor data from an ESP32-based garden monitoring setup.

What it currently does
Android app built in Kotlin
Plant identification through a private FastAPI backend
Live garden sensor data through MQTT
ESP32 sensor integration for temperature, humidity, and soil moisture
Solar/irradiance calculations for garden planning
Local plant photo saving and garden layout tools
Backend services running on a Linux server
Tech I'm using
Kotlin / Android Studio
FastAPI / Python
MQTT / Mosquitto
SQLite
ESP32 / Arduino
Linux / systemd
Tailscale
Git / GitHub
